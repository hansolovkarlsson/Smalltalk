A Smalltalk, built from scratch in C.

An object-oriented, message-passing language and virtual machine, grown one milestone at a time: a tagged object model, real method dispatch, user-defined classes, closures with non-local return, a mark-sweep garbage collector, and finally a bytecode compiler with its own dispatch loop — no framework, no bison/flex, no borrowed VM.

Everything is a message send

st> 3 + 4
7
st> 2 + 3 * 4               "no operator precedence — strictly left to right"
20
st> Object subclass: #Counter instanceVariableNames: 'count'
Counter
st> Counter compile: 'increment  count := count + 1. ^self'
true
st> [:a :b | a * b] value: 6 value: 7
42

There's no special operator syntax anywhere in the language — +, ifTrue:ifFalse:, and a method you define yourself are all handled by exactly the same mechanism: a message sent to a receiver, resolved by walking a class's superclass chain. Once that clicks, the rest of the language falls out of it.

What's inside

Tagged object model

SmallIntegers packed directly into a pointer-sized oop, no heap allocation; everything else a real heap object sharing a common isa layout.

Real message dispatch

No hardcoded operators. Every send — arithmetic included — walks the superclass chain looking up a primitive or a compiled method.

User-defined classes

subclass:instanceVariableNames: and compile: let the language grow itself from inside the REPL — instance variables, self/super, inheritance.

Closures & non-local return

Block literals capture their enclosing activation; ^ unwinds via longjmp back to the lexically enclosing method, however deep the block nesting.

Mark-sweep garbage collection

Precise heap tracing plus a conservative, exact-match scan of the C stack — no shadow stack, no Boehm-style false positives.

Bytecode compiler + VM

Method and block bodies compile once to a flat instruction sequence and run on a dispatch loop, instead of re-walking an AST on every call.

Built incrementally, milestone by milestone

  1. 01 Core object model, message dispatch, REPL
  2. 02 Variables, String/Symbol, printString, cascades
  3. 03 Class-definition syntax + user-defined methods
  4. 04 Block literals, real closures, non-local return, control flow
  5. 05 Mark-sweep garbage collection
  6. 06 Bytecode compiler + VM dispatch loop

See the full roadmap for what each milestone actually changed, with try-it-yourself REPL sessions, plus what's being considered next.

Try it locally

$ git clone https://github.com/hansolovkarlsson/Smalltalk.git
$ cd Smalltalk
$ make
$ ./bin/smalltalk
Smalltalk REPL (milestone 6). Type an expression, or 'quit' to exit.
st> 3 + 4 factorial

make test runs the assert-based regression suite; make examples runs every runnable program under examples/. The tutorial walks through the language itself from a blank REPL.
