# Changelog

*The one page that says **when**, for a reader who is not reading the
source. Only what shipped and is visible from outside: a form that
appeared, a behaviour that changed, a message somebody will now see.
Internal reworking, and the reasoning behind any of it, belongs in [the
journal](work-journal/) instead.*

Smalltalk has not been released, so there are no version numbers yet.
Entries are grouped by the day the work happened, newest first. The six
milestones that landed before this file existed are recorded, with their
commits, in [ROADMAP.md](ROADMAP.md); entries here start with the first
change after that.
